# Автомонтаж рилса

Два скрипта рядом с этим файлом:
- `montage.py` - чистовой монтаж: паузы, дубли, субтитры, громкость. Нужны Python 3, ffmpeg и бесплатный ключ Groq в `GROQ_API_KEY`.
- `oformlenie.py` - оформление поверх чистовика: анимация, звуки, музыка. Дополнительно нужен Node.js: видео рисует HyperFrames.

Главное правило: паузы режет скрипт, по громкости звука. Неудачные дубли ищешь ты, по тексту расшифровки, и вырезаешь только после «да» пользователя. Каждый шаг оформления тоже показываешь и ждёшь «да».

Рабочую папку называй по видео: для `video.mov` это `montage-video` рядом с файлом. Путь к скриптам бери из папки этого скилла.

## Часть 1. Чистовик

1. **Проверка.** `python montage.py check`. Если есть строки с ✗, перескажи их простыми словами и остановись. Ключ никогда не печатай и не пиши в файлы.
2. **Расшифровка по фразам.** `python montage.py phrases ВИДЕО --work ПАПКА`. Названия, которые распознаватель может не знать, передай через `--prompt "Claude, Notion"`.
3. **Поиск дублей.** Прочитай `phrases.txt` и найди места, где человек сбился и начал фразу заново, повторил мысль или бросил её. Покажи список: «12.4-15.9 - первый заход фразы "...", дальше она сказана заново». Жди «да» или поправку. Не нашёл - так и скажи. Границы только из `phrases.txt`; точнее - `raw_transcript.json`, там время каждого слова.
4. **Рез.** `python montage.py cut ВИДЕО --work ПАПКА --drop 12.4-15.9` (`--drop` можно повторять, время - по сырому видео). Перескажи, сколько убрано. «Голос мало громче фона» - предупреди, что рез может задеть слова.
5. **Субтитры.** `python montage.py subs --work ПАПКА`. Покажи `subs.txt`, найди неверно услышанные слова и исправь через `--fix "к лод-коду=Клоду Коду"`, затем `subs` ещё раз (бесплатно, расшифровка сохранена). Фразы не переписывай: субтитры - это то, что человек сказал.
6. **Без оформления** - `python montage.py finish --work ПАПКА --out ИМЯ-готово.mp4`: кадр 1080x1920, субтитры, громкость. На этом можно закончить.

## Часть 2. Оформление (если просят анимацию, звуки или музыку)

7. **Проверка.** `python oformlenie.py check`. Нет Node.js - Windows: `winget install OpenJS.NodeJS.LTS`, Mac: `brew install node`.
8. **Описание оформления** - файл `ПАПКА/design.json`. Окно - на одну мысль речи; время - якорь на произнесённое слово:

```json
{
  "fixes": {"Клод": "Claude", "монтаж": "МОНТАЖ"},
  "windows": [
    {"id": "hook", "title": "claude", "start": 0,
     "html": "<div class=\"prompt\">&gt; замечали?</div><h1 class=\"title\"><img class=\"logo\" id=\"l1\" src=\"{{logo:claude}}\"> <b>Claude</b><br><span id=\"m1\">монтирует видео</span></h1>",
     "anims": [{"kind": "pulse", "sel": "#l1", "at": {"word": "клод"}},
               {"kind": "highlight", "sel": "#m1", "at": {"word": "монтирует"}}]},
    {"id": "list", "title": "что делает", "start": {"word": "убирает"},
     "html": "<div class=\"row\" id=\"r1\"><span class=\"tick\">✓</span>Режет паузы</div><div class=\"row\" id=\"r2\"><span class=\"tick\">✓</span>Делает субтитры</div>",
     "anims": [{"kind": "slide", "sel": "#r1", "at": {"word": "паузы"}}, {"kind": "slide", "sel": "#r2", "at": {"word": "субтитры"}}]},
    {"id": "cta", "title": "комментарии", "start": {"word": "напишите"},
     "html": "<div class=\"prompt\">&gt; напишите</div><div class=\"code\" id=\"cw\"><span class=\"ch\">М</span><span class=\"ch\">О</span><span class=\"ch\">Н</span><span class=\"ch\">Т</span><span class=\"ch\">А</span><span class=\"ch\">Ж</span></div>",
     "anims": [{"kind": "typechars", "sel": "#cw .ch", "at": {"word": "монтаж"}}]}
  ],
  "dynamics": {"at": [{"word": "поэтому"}],
               "schedule": [{"at": 0, "layout": "split"}, {"at": {"word": "поэтому"}, "layout": "visual"},
                            {"at": {"word": "убирает"}, "layout": "split"}, {"at": {"word": "кстати"}, "layout": "speaker"}]},
  "sfx": true,
  "music": {"file": "music/трек.mp3"}
}
```

   - Якорь `{"word": "корень", "after": <якорь>, "offset": 0.4}`: начало слова (по началу слова, без окончания); слово встречается раньше - уточни `after`. Окно длится до следующего.
   - Классы вёрстки - в `terminal.css` (тёмные окна, зелёный акцент): `prompt`, `title`, `logo`, `row`, `tick`, `bubble me|bot`, `fileline`, `file`, `badge`, `steps/step`, `chips/chip`, `code/ch`, `cursor`, `sub`, `phone`, `dim`.
   - Анимации на словах: `pulse`, `pop`, `drop`, `stamp`, `slide`, `fade`, `type`, `fill`, `typechars`, `blink`. Пометка от руки: `highlight` (маркер за словом) и `underline` (двойной росчерк снизу, `"color": "#ffffff"`) - слово оборачиваешь `<span id="…">`. Одна-две на ролик, не на каждом окне.
   - Хук - первое окно, виден целиком с первого кадра. Призыв со словом - последнее окно.
   - **Логотипы только настоящие**: SVG кладёшь в `ПАПКА/logos/имя.svg`, например `https://cdn.jsdelivr.net/gh/gilbarbara/logos/logos/имя.svg`. Сам логотипы не рисуй. Картинки - `ПАПКА/img/имя.jpg`, в HTML `{{img:имя}}`.
   - Числа, примеры и подписи в окнах - только из речи человека.
9. **Кадры.** `python oformlenie.py snapshot --work ПАПКА --step 3 --at 1,6.5,12` (секунда на каждое окно) → `preview.jpg` с зонами Instagram: окна не залезают в красное, ниже жёлтой линии только субтитры. Покажи `preview.jpg`, жди «да».
10. **Динамика** (`--step 4`): кадр меняется каждые 2-4 секунды. `split` - окно сверху, человек снизу; `visual` - окно во весь экран, когда в нём что-то появляется; `speaker` - человек крупно, на шутке или обращении к зрителю. Шторка (`dynamics.at`) - только на двух сильных поворотах: «проблема → решение» и вход в призыв. Покажи кадры смен, жди «да».
11. **Звуки** - `"sfx": true`: вжух на шторке, щелчок на окне, поп на появлении, дзынь на призыве. Тише или громче - `"sfx": {"volume": -3}`.
   Человек сам называет звук («вжух», «щелчок») - поставь его на это слово и сделай слышным поверх голоса: `"sfx": {"events": [{"at": {"word": "вжух"}, "sound": "whoosh", "volume": 10}, {"at": {"word": "щелчок", "offset": 0.32}, "sound": "click", "volume": 12}]}` - щелчок в паузу сразу после слова, иначе его перекроет «щ».
12. **Музыка** - трек пользователя или сгенерированный. Генерация (Suno через KIE и т. п.) тратит деньги: сначала назови сервис, цену и жди «да». Только без слов (инструментал). Файл - в `ПАПКА/music/`, в `design.json` - `"music": {"file": "music/трек.mp3"}`. Под речью музыка сама приглушается, в паузах чуть громче, входит и затухает мягко. Громкость - `level` (по умолчанию -16: на столько дБ тише голоса), `start` - с какой секунды трека начать.
13. **Сборка.** `python oformlenie.py render --work ПАПКА --out ИМЯ-готово.mp4` - несколько минут. Назови путь, длительность, громкость. Музыку или звуки поправить без новой сборки: `python oformlenie.py remix --work ПАПКА --out ИМЯ-готово.mp4` (секунды).

## Настройки по умолчанию

- Пауза короче 0,4 с остаётся: так речь звучит живо. Порог тишины скрипт считает сам, видно в выводе `cut`.
- Субтитры: до 24 знаков, белые с чёрной обводкой; в оформлении звучащее слово жёлтое, нижний край - 1730 из 1920.
- Громкость -14 LUFS, как у Instagram и YouTube.

## Чего скилл не делает

Кадр за лицом не ведёт, горизонтальное видео не берёт, обрабатывает один файл за раз. Музыку сам не выбирает и не генерирует без «да».

Groq отвечает «403» или не скачивается шрифт/GSAP - нужен VPN.
