# Автомонтаж рилса

Вся работа идёт через скрипт `montage.py`, он лежит рядом с этим файлом. Ему нужны Python 3, ffmpeg и бесплатный ключ Groq в переменной `GROQ_API_KEY`.

Главное правило: паузы режет скрипт, по громкости звука. Неудачные дубли и повторы ищешь ты, по тексту расшифровки, и вырезаешь только после «да» пользователя.

## Порядок

Рабочую папку называй по видео: для `video.mov` это `montage-video` рядом с файлом. Путь к скрипту бери из папки этого скилла.

1. **Проверка.** `python montage.py check`. Если есть строки с ✗, перескажи их простыми словами и остановись. Ключ никогда не печатай и не пиши в файлы.
2. **Расшифровка по фразам.** `python montage.py phrases ВИДЕО --work ПАПКА`. Если в речи есть названия, которые распознаватель может не знать, передай их через `--prompt "Claude, Notion"`.
3. **Поиск дублей.** Прочитай `phrases.txt` и найди места, где человек сбился и начал фразу заново, повторил мысль или бросил её на середине. Покажи список: «12.4-15.9 - первый заход фразы "...", дальше она сказана заново». Пусть пользователь ответит «да» или поправит. Не нашёл повторов - так и скажи. Границы бери только из `phrases.txt`, не выдумывай. Нужно точнее - открой `raw_transcript.json`, там время каждого слова.
4. **Рез.** `python montage.py cut ВИДЕО --work ПАПКА --drop 12.4-15.9` (`--drop` можно повторять, время - по сырому видео). Перескажи, сколько секунд убрано. Если скрипт пишет «голос мало громче фона», предупреди: рез может задеть слова.
5. **Субтитры.** `python montage.py subs --work ПАПКА`. Покажи пользователю `subs.txt` и найди слова, которые распознаватель услышал неправильно. Исправь их через `--fix "к лод-коду=Клоду Коду"` и запусти `subs` ещё раз. Расшифровку он берёт из сохранённой копии, поэтому повтор бесплатный. Сам фразы не переписывай: субтитры - это то, что человек сказал.
6. **Сборка.** `python montage.py finish --work ПАПКА --out ИМЯ-готово.mp4`. Скрипт приводит кадр к 1080x1920, накладывает субтитры и выравнивает громкость. Назови путь к файлу, длительность и громкость.
7. **Правки.** Просят сделать субтитры крупнее, выше или другим шрифтом - пересобери `subs` с `--size 84`, `--bottom 1500`, `--font "Montserrat"`, потом снова `finish`. Слово обрезано на стыке - уменьши `--drop` или задай порог тише, например `--floor -55`. После этого повтори `cut`, `subs --retranscribe` и `finish`.

## Настройки по умолчанию

- Пауза короче 0,4 с остаётся: так речь звучит живо. Перед словом остаётся 0,12 с, после - 0,2 с, чтобы не съедались окончания.
- Порог тишины скрипт считает сам по записи. Видно его в выводе `cut`.
- Субтитры: до 24 знаков в строке, белые с чёрной обводкой. Нижний край на высоте 1560 из 1920 - выше подписи и кнопок Instagram.
- Громкость -14 LUFS, как у Instagram и YouTube.

## Чего скилл не делает

Музыку, заставки, плашки и инфографику не накладывает, кадр за лицом не ведёт. Горизонтальное видео не берёт: рилс снимают вертикально. Обрабатывает один файл за раз.

Если Groq отвечает «403», сервис недоступен из сети пользователя: нужен VPN.
