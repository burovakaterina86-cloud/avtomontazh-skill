# Автомонтаж рилса в Claude Code

Как и обещала - вот как сделать, чтобы Клод монтировал ролики за тебя. Теперь не только чистовик, но и оформление.

Проще говоря, ты даёшь Клоду сырое видео, где говоришь в камеру. Он вырезает паузы и неудачные дубли, делает субтитры и выравнивает громкость. А если попросишь - ещё и оформляет: окна и плашки появляются на твоих словах, кадр меняется, главное слово подчёркнуто маркером, на переходах звуки, под голосом музыка.

## Что здесь лежит

🔹 `avtomontazh/SKILL.md` - инструкция для Клода: в каком порядке монтировать и о чём спрашивать тебя
🔹 `avtomontazh/montage.py` - программа, которая режет видео и делает субтитры
🔹 `avtomontazh/oformlenie.py` - программа оформления: анимация, звуки, музыка
🔹 `avtomontazh/terminal.css` - внешний вид окон: тёмные, с зелёным акцентом
🔹 этот файл - инструкция для тебя

## Что понадобится

🔹 **Claude Code** - Клод на компьютере, он работает с файлами. Нужна подписка Claude.
🔹 **Python** - на нём написаны обе программы.
🔹 **ffmpeg** - бесплатная программа, которая режет и склеивает видео.
🔹 **Ключ Groq** - бесплатный ключ для распознавания речи, по нему делаются субтитры.
🔹 **Node.js** - нужен только для оформления: через него видео рисует HyperFrames.

Важно: ❗️ если Claude или Groq не открываются, нужен VPN.

## Как поставить - пошагово

**1. Python, ffmpeg и Node.js.**
Windows: открой «Терминал» и вставь по очереди:
```
winget install Python.Python.3.12
winget install Gyan.FFmpeg
winget install OpenJS.NodeJS.LTS
```
Mac (нужен Homebrew, brew.sh): `brew install python ffmpeg node`

После установки закрой терминал и открой заново.

**2. Ключ Groq.**
Зайди на console.groq.com, войди и нажми API Keys → Create API Key. Скопируй ключ.

Windows, в терминале:
```
setx GROQ_API_KEY "сюда-твой-ключ"
```
Mac: `echo 'export GROQ_API_KEY="сюда-твой-ключ"' >> ~/.zshrc`

Ещё раз закрой и открой терминал. Ключ никому не показывай.

**3. Скилл.**
Вверху этой страницы нажми зелёную кнопку **Code** → **Download ZIP** и распакуй архив. Папку `avtomontazh` из него положи сюда:
Windows - `C:\Users\ТВОЁ-ИМЯ\.claude\skills\`
Mac - `~/.claude/skills/`

Если папки `skills` нет, создай её. Если стоит прошлая версия - замени папку целиком.

**4. Проверка.**
Запусти Claude Code и напиши: «проверь, готов ли автомонтаж и оформление». Он сам посмотрит, всё ли стоит, и скажет, чего не хватает. При первом оформлении программа один раз скачает шрифт и библиотеку анимации - нужен интернет.

## Как пользоваться

Сними видео вертикально и напиши Клоду:
«Смонтируй рилс из файла C:\Видео\дубль.mov»

Дальше он:
➡️ расшифрует речь и покажет неудачные дубли. Ответь «да» или поправь
➡️ вырежет паузы и эти куски
➡️ покажет субтитры - проверь, правильно ли он услышал слова
➡️ соберёт чистовик 1080×1920

Хочешь оформление - так и напиши: «оформи ролик: анимация, звуки и музыка». Тогда он:
➡️ разложит речь на окна и покажет кадры - проверь, ничего ли не залезает под кнопки Instagram
➡️ добавит смену кадра и шторку на переходах - снова покажет
➡️ поставит звуки на переходы и окна
➡️ подложит музыку и соберёт готовый ролик

**Про музыку.** Можно дать свой трек: положи файл в рабочую папку и скажи Клоду. А можно сгенерировать - например, в Suno. Генерация стоит денег, поэтому Клод сначала назовёт цену и подождёт твоего «да». Музыка без слов, под речью она сама становится тише.

Что-то не понравилось? Напиши в чате: «субтитры крупнее», «музыку тише», «убери шторку», «верни кусок на 12 секунде». Он переделает.

## Что проверить руками

Это не волшебная кнопка.
🔹 посмотри стыки: не съелось ли начало или конец слова
🔹 прочитай субтитры: названия и редкие слова распознаватель иногда слышит по-своему
🔹 проверь, что окна и логотипы не закрывают лицо
🔹 послушай звук в наушниках: музыка не должна перебивать голос
